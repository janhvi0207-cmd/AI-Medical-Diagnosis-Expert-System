What this project does

✚

Symptom assessment

Structured Yes / No / Not Sure questions about common symptoms. "No" and "Not Sure" are kept strictly separate.

⚙

AI reasoning

A Python expert system applies illustrative if-then rules with two different inference strategies and explains each step.

⚠

Safety first

Urgent warning signs are checked separately from the rules and always shown first. Results are educational possibilities, never diagnoses.

How it works

Both algorithms use the same answers and the same rules. They differ in the direction they reason.

Data-driven

Forward chaining

  1. Start with the facts from your Yes answers.
  2. Find rules whose conditions are all satisfied.
  3. Fire them to add new facts (e.g. "nasal symptoms present").
  4. Repeat until no new facts appear.

Facts → rules → new facts → patterns

Goal-driven

Backward chaining

  1. Pick a hypothesis, e.g. "flu-like pattern".
  2. Find the rules that could conclude it.
  3. Treat each condition as a sub-goal and prove it recursively.
  4. Report supported, unsupported or inconclusive.

Goal → rules → conditions → known facts

Please read before you start

  • This is a learning tool. It does not diagnose, confirm or rule out any disease, and it does not suggest medicines or doses.
  • The rules are small illustrative examples, not medically validated.
  • If you have severe breathing difficulty, chest pain, confusion or blue lips, seek emergency help immediately.
  • No names, contact details or other personal information are collected.
